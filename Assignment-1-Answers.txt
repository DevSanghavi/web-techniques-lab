### **Unit 1 & Unit 2 – Assignment 1**

#### **Question 1: Create a webpage using HTML5 semantic elements and demonstrate grouping using `<div>` and `<span>`.** *(2 Marks)*

---

### **1. Concept Explanation**

* **HTML5 Semantic Elements:** Elements like `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` clearly describe their structural purpose to both browsers and assistive tools. They replace generic containers with meaningful tags to improve webpage accessibility, maintainability, and Search Engine Optimization (SEO).
* **Grouping Elements (`<div>` vs `<span>`):**
  * **`<div>` (Block-level Grouping):** A generic block container used to group multiple elements together for layout structuring or styling without adding semantic meaning. It starts on a new line and spans the full available width.
  * **`<span>` (Inline-level Grouping):** A generic inline container used to group small portions of text or inline content within a paragraph or block without starting a new line.

---

### **2. Complete HTML5 Code**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML5 Semantic Webpage Demo</title>
  <style>
    /* Simple inline styles to highlight grouping elements */
    body { font-family: Arial, sans-serif; margin: 20px; line-height: 1.6; }
    header, nav, main, section, article, footer { border: 1px solid #ccc; padding: 15px; margin-bottom: 10px; }
    
    /* Styling for block-level grouping (div) */
    .card-group { background-color: #f4f4f4; border-radius: 5px; padding: 10px; margin-top: 10px; }
    
    /* Styling for inline-level grouping (span) */
    .highlight { color: #d9534f; font-weight: bold; }
    .badge { background-color: #5bc0de; color: white; padding: 2px 6px; border-radius: 3px; font-size: 0.9em; }
  </style>
</head>
<body>

  <!-- Semantic Header -->
  <header>
    <h1>Web Techniques Department</h1>
    <p>Welcome to <span class="highlight">MIT ACSC</span> Learning Portal</p>
  </header>

  <!-- Semantic Navigation -->
  <nav>
    <a href="#home">Home</a> | 
    <a href="#courses">Courses</a> | 
    <a href="#contact">Contact</a>
  </nav>

  <!-- Semantic Main Content Area -->
  <main>
    
    <!-- Semantic Section -->
    <section id="courses">
      <h2>Featured IT Course</h2>

      <!-- Semantic Article -->
      <article>
        <h3>Web Techniques (2417MJCT101)</h3>
        <p>This course covers <span class="highlight">HTML5</span>, Bootstrap, and JavaScript basics.</p>

        <!-- Block-Level Grouping using <div> -->
        <div class="card-group">
          <h4>Course Overview</h4>
          <p>Status: <span class="badge">Active</span></p>
          <p>Duration: <span class="badge">15 Weeks</span></p>
        </div>
      </article>

    </section>

  </main>

  <!-- Semantic Footer -->
  <footer>
    <p>&copy; 2026 MIT Arts, Commerce and Science College, Alandi (D), Pune.</p>
  </footer>

</body>
</html>
```

---

### **3. Key Implementation Highlights**

1. **Semantic Layout Elements Used:**
   * `<header>`: Contains the page heading banner.
   * `<nav>`: Contains top navigation links.
   * `<main>`: Encloses the unique primary content of the webpage.
   * `<section>`: Divides content into thematic sections.
   * `<article>`: Wraps a self-contained content block for the course.
   * `<footer>`: Contains copyright and institutional details.

2. **Grouping Elements Demonstrated:**
   * **`<div>` (Block Grouping):** Encloses the `.card-group` container holding the course overview heading and paragraph elements together as a single visual card.
   * **`<span>` (Inline Grouping):** Used inside paragraphs to apply targeted CSS classes (`.highlight` and `.badge`) to specific text phrases without breaking the line flow.

### **Unit 1 & Unit 2 – Assignment 1**

#### **Question 2: Add images with appropriate `alt` text and demonstrate responsive images using `srcset` and `<picture>`.** *(2 Marks)*

---

### **1. Concept Explanation**

* **`alt` Attribute (From Your Sources):** The `alt` (alternate text) attribute describes the content of an image. It is rendered if the image fails to load due to a broken path or slow network connection, and it is read aloud by screen readers for web accessibility.
* **Responsive Images (`srcset` & `<picture>`) (HTML5 Specification):**
  * **`srcset` Attribute:** Provides a list of different image sources along with width descriptors (e.g., `400w`, `800w`) or pixel densities, allowing the browser to automatically download the optimal image size based on the user's screen width.
  * **`<picture>` Element:** A wrapper element containing one or more `<source>` tags with `media` queries and a fallback `<img>` tag. It allows developers to specify completely different image files or formats depending on device screen dimensions (art direction).

---

### **2. Complete HTML5 Code**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Responsive Images Demo</title>
  <style>
    body { font-family: Arial, sans-serif; margin: 20px; line-height: 1.6; }
    .image-container { margin-bottom: 30px; padding: 15px; border: 1px solid #ddd; border-radius: 5px; }
    img { max-width: 100%; height: auto; }
  </style>
</head>
<body>

  <h1>HTML5 Image Demonstration</h1>

  <!-- 1. Standard Image with Alt Text -->
  <div class="image-container">
    <h3>1. Standard Image with Descriptive Alt Text</h3>
    <img src="https://picsum.photos/200" alt="Random placeholder sample image for testing">
  </div>

  <!-- 2. Responsive Image using srcset & sizes -->
  <div class="image-container">
    <h3>2. Responsive Image using 'srcset' (Resolution Switching)</h3>
    <img 
      src="[suspicious link removed]" 
      srcset="https://picsum.photos/200 300w, 
              [suspicious link removed] 600w, 
              [suspicious link removed] 1200w"
      sizes="(max-width: 600px) 200px, (max-width: 1200px) 400px, 800px"
      alt="Responsive landscape placeholder photo">
  </div>

  <!-- 3. Responsive Image using the <picture> Element -->
  <div class="image-container">
    <h3>3. Art Direction using the &lt;picture&gt; Element</h3>
    <picture>
      <!-- Display large 800px image for viewports 800px or wider -->
      <source media="(min-width: 800px)" srcset="[suspicious link removed]">
      
      <!-- Display medium 500px image for viewports 500px or wider -->
      <source media="(min-width: 500px)" srcset="[suspicious link removed]">
      
      <!-- Fallback img element for smaller screens or unsupported browsers -->
      <img src="https://picsum.photos/200" alt="Fallback testing photo">
    </picture>
  </div>

</body>
</html>
```

---

### **3. Key Implementation Highlights**

1. **Standard `<img>` with `alt` Text:**
   * Includes `alt="Random placeholder sample image for testing"` to ensure screen reader accessibility and text fallback if the image fails to load.
2. **`srcset` and `sizes` (Resolution Switching):**
   * Supplies three image resolutions (`200px`, `400px`, `800px` from Picsum).
   * The browser evaluates the viewport width via the `sizes` attribute and automatically selects the smallest suitable image, saving bandwidth on mobile devices.
3. **`<picture>` Element (Art Direction):**
   * Uses `<source media="(min-width: 800px)">` to deliver a wide banner image (`800x400`) on desktop viewports.
   * Uses `<source media="(min-width: 500px)">` to deliver a medium image (`500x300`) on tablet viewports.
   * Falls back to the default `200px` image for mobile viewports.

### **Unit 1 & Unit 2 – Assignment 1**

#### **Question 3: Create a table using `<thead>`, `<tbody>`, `<tfoot>`, `rowspan`, and `colspan`.** *(2 Marks)*

---

### **1. Concept Explanation**

* **Structural Grouping Tags (`<thead>`, `<tbody>`, `<tfoot>`):**
  * **`<thead>` (Table Header):** Groups the header rows (`<tr>`) and header cells (`<th>`) that define column titles.
  * **`<tbody>` (Table Body):** Encapsulates the main dataset rows containing standard data cells (`<td>`).
  * **`<tfoot>` (Table Footer):** Groups summary rows at the bottom of the table, typically used for calculations, totals, or metadata.
* **Cell Spanning Attributes (`rowspan` & `colspan`):**
  * **`colspan` (Column Span):** Merges a single cell horizontally across multiple adjacent columns.
  * **`rowspan` (Row Span):** Merges a single cell vertically across multiple adjacent rows.

---

### **2. Complete HTML5 Code**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML5 Table with Rowspan and Colspan</title>
  <style>
    body { font-family: Arial, sans-serif; margin: 20px; line-height: 1.6; }
    table { width: 100%; border-collapse: collapse; margin-top: 15px; }
    th, td { border: 1px solid #333; padding: 10px; text-align: center; }
    thead { background-color: #337ab7; color: white; }
    tfoot { background-color: #f5f5f5; font-weight: bold; }
    tbody tr:nth-child(even) { background-color: #f9f9f9; }
  </style>
</head>
<body>

  <h2>Student Marksheet Summary</h2>

  <table>
    <!-- Table Header Group -->
    <thead>
      <tr>
        <th rowspan="2">Roll No</th>
        <th rowspan="2">Student Name</th>
        <th colspan="2">Marks Obtained</th>
        <th rowspan="2">Grade</th>
      </tr>
      <tr>
        <th>Web Techniques</th>
        <th>Database Systems</th>
      </tr>
    </thead>

    <!-- Table Body Group -->
    <tbody>
      <tr>
        <td>101</td>
        <td>Rahul Sharma</td>
        <td>85</td>
        <td>90</td>
        <td rowspan="2">A</td> <!-- Vertical Span across 2 rows -->
      </tr>
      <tr>
        <td>102</td>
        <td>Priya Verma</td>
        <td>88</td>
        <td>92</td>
      </tr>
      <tr>
        <td>103</td>
        <td>Amit Patel</td>
        <td>75</td>
        <td>78</td>
        <td>B</td>
      </tr>
    </tbody>

    <!-- Table Footer Group -->
    <tfoot>
      <tr>
        <td colspan="2">Total Students Passed</td> <!-- Horizontal Span across 2 columns -->
        <td colspan="3">3 Students</td>             <!-- Horizontal Span across 3 columns -->
      </tr>
    </tfoot>
  </table>

</body>
</html>
```

---

### **3. Key Implementation Highlights**

1. **Table Structure:**
   * **`<thead>`**: Contains two rows defining a multi-level header.
   * **`<tbody>`**: Contains student performance data rows.
   * **`<tfoot>`**: Displays a summary row at the bottom of the table.

2. **Spanning Demonstrated:**
   * **`colspan="2"` (in `<thead>`):** Merges the header cell *"Marks Obtained"* across two sub-columns (*Web Techniques* and *Database Systems*).
   * **`rowspan="2"` (in `<thead>`):** Extends *"Roll No"*, *"Student Name"*, and *"Grade"* downward across both header rows.
   * **`rowspan="2"` (in `<tbody>`):** Merges the Grade cell (`"A"`) vertically across Roll No 101 and 102.
   * **`colspan="2"` & `colspan="3"` (in `<tfoot>`):** Spans footer summary cells horizontally to align totals across the 5 total table columns.

### **Unit 1 & Unit 2 – Assignment 1**

#### **Question 4: Design an HTML form with submission and file upload functionality.** *(2 Marks)*

---

### **1. Concept Explanation**

* **`<form>` Container:** The `<form>` tag is used to collect user input and submit it to a server-side script or process.
* **Form Submission Attributes:**
  * **`action`:** Specifies the URL/path where the form data is sent upon submission.
  * **`method="POST"`:** Sends data inside the HTTP request body without size limitations, making it ideal for submitting form inputs and binary file data securely.
  * **`enctype="multipart/form-data"`:** Required whenever a form includes a file upload element. It ensures that binary file content is encoded properly when sent to the server.
* **File Upload Input (`<input type="file">`):** Allows users to select one or more files from their local storage device to upload. Adding the `multiple` attribute enables selecting multiple files simultaneously.
* **Submit Button (`<input type="submit">`):** Triggers the form submission process.

---

### **2. Complete HTML5 Code**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML5 Form with File Upload</title>
  <style>
    body { font-family: Arial, sans-serif; margin: 30px; line-height: 1.6; }
    .form-container { max-width: 500px; padding: 20px; border: 1px solid #ccc; border-radius: 8px; background-color: #f9f9f9; }
    .form-group { margin-bottom: 15px; }
    label { display: block; font-weight: bold; margin-bottom: 5px; }
    input[type="text"], input[type="email"], input[type="file"] { width: 100%; padding: 8px; box-sizing: border-box; }
    input[type="submit"] { background-color: #28a745; color: white; padding: 10px 15px; border: none; border-radius: 4px; cursor: pointer; }
    input[type="submit"]:hover { background-color: #218838; }
  </style>
</head>
<body>

  <div class="form-container">
    <h2>Student Document Submission Form</h2>

    <!-- Form with POST method and multipart encoding for file upload -->
    <form action="/upload_page.php" method="POST" enctype="multipart/form-data">
      
      <!-- Text Input -->
      <div class="form-group">
        <label for="fullName">Full Name:</label>
        <input type="text" id="fullName" name="fullName" placeholder="Enter your full name" required>
      </div>

      <!-- Email Input -->
      <div class="form-group">
        <label for="userEmail">Email Address:</label>
        <input type="email" id="userEmail" name="userEmail" placeholder="Enter your email" required>
      </div>

      <!-- File Upload Input (Single File) -->
      <div class="form-group">
        <label for="identityDoc">Upload Identity Proof (PDF/Image):</label>
        <input type="file" id="identityDoc" name="identityDoc" accept=".pdf, image/*" required>
      </div>

      <!-- File Upload Input (Multiple Files) -->
      <div class="form-group">
        <label for="certificates">Upload Academic Certificates (Multiple):</label>
        <input type="file" id="certificates" name="certificates" multiple>
      </div>

      <!-- Submit Button -->
      <div class="form-group">
        <input type="submit" value="Submit Application">
      </div>

    </form>
  </div>

</body>
</html>
```

---

### **3. Key Implementation Highlights**

1. **`enctype="multipart/form-data"`:** Included on the `<form>` element so the browser treats the form data as multi-part binary data, allowing file uploads to reach the server properly.
2. **`method="POST"`:** Used instead of `GET` because binary files cannot be appended to a URL.
3. **Single File Upload (`<input type="file">`):** Prompts the user to pick a document from their device storage.
4. **Multiple File Upload (`multiple` attribute):** Allows users to select more than one file at a time in a single upload field.
5. **Native Form Submission:** Clicking `<input type="submit">` triggers browser validation for `required` fields before submitting the payload to `/upload_page.php`.

#### **Question 6: Demonstrate one Bootstrap form layout: vertical, horizontal or inline.** *(1 Mark)*

---

### **1. Concept Explanation**

Bootstrap provides three primary form layout options to organize user inputs:
* **Vertical Form Layout (Default):** Form labels and input fields stack on top of each other. This is the default form behavior in Bootstrap.
* **Horizontal Form Layout:** Labels and input fields sit side-by-side using the Bootstrap grid system (`.row` and `.col-*-*` classes).
* **Inline Form Layout:** Arranges all labels, controls, and buttons on a single horizontal line, which is ideal for compact interfaces like search bars.

*(The code below demonstrates the **Horizontal Form Layout** using grid column classes).*

            const form = document.getElementById("regForm");

            // Regular expressions used for validation
            const emailPattern = /^[\w.-]+@[\w-]+\.[a-zA-Z]{2,}$/; // user@example.com
            const phonePattern = /^\d{10}$/; // exactly 10 digits

            // Marks a field as valid (green) or invalid (red) and returns the result
            function setState(field, isValid) {
                field.classList.toggle("is-valid", isValid);
                field.classList.toggle("is-invalid", !isValid);
                return isValid;
            }

            // One check function for each field
            const checks = [
                () => setState(fullName, fullName.value.trim().length >= 3),
                () => setState(email, emailPattern.test(email.value.trim())),
                () => setState(phone, phonePattern.test(phone.value.trim())),
                () => setState(password, password.value.length >= 6),
                () => setState(course, course.value !== ""),
                () => setState(agree, agree.checked),
            ];

            // Check each text field when the user leaves it (blur event)
            [fullName, email, phone, password].forEach(function (field, index) {
                field.addEventListener("blur", checks[index]);
            });

            // Show / hide the password
            const toggleButton = document.getElementById("togglePwd");
            toggleButton.addEventListener("click", function () {
                const hidden = password.type === "password";
                password.type = hidden ? "text" : "password";
                toggleButton.textContent = hidden ? "Hide" : "Show";
            });

            // Handle form submit
            form.addEventListener("submit", function (event) {
                event.preventDefault(); // stop the page from reloading

                // Run every check (map runs all of them, so every error is shown at once)
                const allValid = checks
                    .map(function (check) {
                        return check();
                    })
                    .every(function (ok) {
                        return ok;
                    });

                if (allValid) {
                    resultMsg.textContent =
                        "Thank you, " +
                        fullName.value.trim() +
                        "! You are registered for " +
                        course.value +
                        ".";
                    resultMsg.classList.remove("d-none");
                    form.reset();
                    form.querySelectorAll(".is-valid").forEach(function (el) {
                        el.classList.remove("is-valid");
                    });
                } else {
                    resultMsg.classList.add("d-none");
                }
            });

            // Clear all messages when the form is reset
            form.addEventListener("reset", function () {
                form.querySelectorAll(".is-valid, .is-invalid").forEach(
                    function (el) {
                        el.classList.remove("is-valid", "is-invalid");
                    },
                );
                resultMsg.classList.add("d-none");
            });

### **1. Concept Explanation**

* **Inline Frame (`<iframe>`):** The `<iframe>` tag embeds an external HTML document or web page within the current page, acting as a separate browsing context.
* **Demonstrating `target` with `<iframe>`:** 
  * To target an inline frame, the `<iframe>` element must be assigned a unique **`name` attribute** (e.g., `<iframe name="contentFrame">`).
  * Hyperlinks (`<a>`) or forms (`<form>`) can then specify **`target="contentFrame"`**. When a user clicks the link, the destination URL loads directly *inside* that designated iframe rather than navigating away from the current page or opening a new tab.

#### **Question 1: Demonstrate JavaScript data types, keywords, and operators.** *(2 Marks)*

### **1. Concept Explanation**

* **Keywords:** Reserved words in JavaScript that have predefined meanings and cannot be used as variable or function names. Examples include declaration keywords (`var`, `let`, `const`, `function`), control flow keywords (`if`, `else`, `return`), and operator keywords (`typeof`, `new`, `this`).
* **Data Types:** JavaScript is a dynamically typed language where variable types are evaluated at runtime. Data types are divided into:
  1. **Primitive Data Types (Immutable, stored by value):** `Number`, `String`, `Boolean`, `Undefined`, `Null`, `Symbol` (ES6), and `BigInt` (ES2020).
  2. **Non-Primitive / Reference Data Types (Mutable, stored by reference):** `Object`, `Array`, and `Function`.
* **Operators:** Symbols used to compute or evaluate values:
  * **Arithmetic Operators:** `+`, `-`, `*`, `/`, `%`.
  * **Assignment Operators:** `=`, `+=`, `-=`, `*=`, `/=`.
  * **Comparison Operators:** `==` (loose equality with type coercion) vs. `===` (strict equality checking both value and type), `!=`, `!==`, `>`, `<`, `>=`, `<=`.
  * **Logical Operators:** `&&` (AND), `||` (OR), `!` (NOT).
  * **Type Operator:** `typeof` returns the data type of a variable or value.

#### **Section Q2: JavaScript (13 Marks)**
#### **Question 2: Implement conditional statements and loops.** *(2 Marks)*

---

### **1. Concept Explanation**

* **Conditional Statements:** Used to execute different blocks of code based on logical conditions:
  * `if / else if / else`: Evaluates boolean conditions sequentially; executes the first block where the condition evaluates to `true`.
  * `switch`: Evaluates an expression against multiple `case` values and executes matching statements until a `break` is encountered.
* **Loops (Control Structures):** Used to repeatedly execute a block of code as long as a specified condition remains true:
  * `for` loop: Used when the exact number of iterations is known in advance.
  * `while` loop: Checks the condition *before* each iteration (pre-test loop).
  * `do...while` loop: Checks the condition *after* each iteration (post-test loop), guaranteeing execution at least once.
  * `for...in` loop: Iterates over enumerable property keys of an object.
  * `for...of` loop: Iterates over values of an iterable object (such as an array).

```html
    let age = 17;
    let category;
    if (age < 13) {

    } else if (age < 20) {
      category = "Teenager";
    } else {
      category = "Adult";

    // 8. for...in loop (keys of an object)

    let pairs = [];
    for (let key in student) {
      pairs.push(`<b>${key}</b>: ${student[key]}`);
    }
    addCard("for...in (object keys)", pairs);

    // 9. for...of loop (values of an array) + break/continue
    let subjects = ["HTML5", "Bootstrap", "JavaScript", "DOM", "jQuery", "JSON"];
    let shown = [];
    for (let sub of subjects) {
      if (sub === "Bootstrap") continue;   // skip this value
      if (sub === "JSON") break;           // stop the loop here

    addCard("for...of (array values)", [
```

#### **Section Q2: JavaScript (13 Marks)**
#### **Question 3: Create functions using parameters and return values. Demonstrate local and global variables.** *(2 Marks)*

---

### **1. Concept Explanation**

* **Functions:** A reusable block of code designed to perform a specific task. Functions reduce code duplication and help organize logic into modular components.
* **Parameters and Arguments:**
  * **Parameters:** Variables declared in the function header that act as placeholders for incoming data.
  * **Arguments:** The actual values supplied to the function when it is invoked/called.
  * **Default Parameters:** Fallback values assigned to parameters if no argument is passed during function invocation.
* **Return Values:** 
  * The `return` statement immediately terminates function execution and sends a value back to the caller.
  * If a function executes without an explicit `return` statement, it automatically returns `undefined`.
* **Local vs. Global Variables (Scope):**
  * **Global Variables:** Variables declared *outside* any function; they are accessible from anywhere throughout the script.
  * **Local Variables:** Variables declared *inside* a function; they are accessible only within that specific function's scope. Attempting to access them outside the function causes a reference error.

### **Unit 2 – Basics of JavaScript**

#### **Section Q2: JavaScript (13 Marks)**
#### **Question 4: Create and manipulate arrays using array access methods.** *(2 Marks)*

---

### **1. Concept Explanation**

* **Array Declaration:** An array is an ordered collection of values stored under a single variable name. It can be declared using:
  1. **Array Literal Syntax (`[...]`):** The standard and recommended syntax.
  2. **Array Constructor (`new Array(...)`):** Initializing using the `Array` function.
* **Accessing Array Elements:** Elements are retrieved using **zero-based indexing** (`arr`), and the total number of items is given by the **`length` property**.
* **Array Access & Manipulation Methods (from Unit 2 notes):**
  * **`push()` / `pop()`:** Add to or remove from the end of the array.
  * **`unshift()` / `shift()`:** Add to or remove from the beginning of the array.
  * **`splice()`:** Destructively inserts, removes, or replaces elements at a given index.
  * **`slice()`:** Non-destructively extracts a portion of the array.
  * **`indexOf()` / `includes()`:** Search for an element's index position or check for its existence (`true`/`false`).
  * **`map()` / `filter()`:** Transform array elements or filter them based on a condition into a new array.
  * **`join()`:** Converts array elements into a formatted string.

```html
    const app = document.getElementById("app");

    // Helper: shows an array as small boxes
    function boxes(arr) {

        ? arr.map(x => `<span class="item">${x}</span>`).join("")
        : `<span class="item">(empty)</span>`;

    // Helper: adds a section heading
    function section(title) {

      h.className = "section";
      h.textContent = title;

    // ================= 4. SPLICE (destructive) vs SLICE (non-destructive) =================
    section("4. splice() changes the array, slice() does not");

    fruits.splice(1, 0, "kiwi");                     // at index 1, remove 0, insert "kiwi"
    step('fruits.splice(1, 0, "kiwi")', boxes(fruits), "Insert: remove 0 items, add kiwi at index 1");

    fruits.splice(2, 1, "papaya");                   // at index 2, remove 1, insert "papaya"
    step('fruits.splice(2, 1, "papaya")', boxes(fruits), "Replace: remove 1 item at index 2, add papaya");

    let removed = fruits.splice(0, 1);               // at index 0, remove 1
    step("fruits.splice(0, 1)", boxes(fruits) + ` removed: ${boxes(removed)}`, "Delete: remove 1 item at index 0");

    let part = fruits.slice(0, 2);                   // copy index 0 and 1 (end index not included)

    // ================= 5. ITERATION AND TRANSFORMATION =================
    section("5. Looping and transforming");

    let lines = [];

    step("fruits.map(f => f.toUpperCase())", boxes(fruits.map(f => f.toUpperCase())), "Makes a NEW array");
    step("fruits.filter(f => f.length > 5)", boxes(fruits.filter(f => f.length > 5)), "Keeps only matching elements");
    step("numbers.reduce((acc, n) => acc + n, 0)",
         `<span class="val">${numbers.reduce((acc, n) => acc + n, 0)}</span>`, "Adds all numbers into one value");

    // ================= 6. SORT, REVERSE, JOIN =================
    section("6. Sorting, reversing and joining");

    let sorted = [...fruits].sort();                 // copy first, so 'fruits' keeps its order
    step("[...fruits].sort()", boxes(sorted), "Alphabetical order (on a copy)");

    let reversed = [...fruits].reverse();
    step("[...fruits].reverse()", boxes(reversed), "Reverse order (on a copy)");

    step('fruits.join(", ")', `<span class="val">${fruits.join(", ")}</span>`, "Array converted to a string");
    step("final fruits array", boxes(fruits), `Length is now ${fruits.length}`);
  </script>
</body>
</html>
```

3. **Array Mutation:** Executes `push()`, `pop()`, `unshift()`, `shift()`, and `splice()` to modify array elements.

### **Unit 2 – Basics of JavaScript**

#### **Section Q2: JavaScript (13 Marks)**
#### **Question 5: Create JavaScript objects and access their properties.** *(2 Marks)*

---

### **1. Concept Explanation**

* **JavaScript Objects:** An **object** in JavaScript is a non-primitive (reference) data type that stores a collection of key-value pairs representing real-world entities. 
  * **Properties:** Key-value pairs holding data values.
  * **Methods:** Functions defined as properties of an object that perform actions using the `this` keyword to access internal properties.

* **Ways to Create Objects in JavaScript (from Unit 2 notes):**
  1. **Object Literal Syntax (`{}`):** The simplest and most common method using curly braces to define key-value pairs.
  2. **`new Object()` Constructor:** Instantiating an empty object and dynamically attaching properties.
  3. **Constructor Function:** A reusable template function invoked with the `new` keyword to instantiate multiple objects.
  4. **ES6 Classes:** Modern class syntax using a `constructor()` method.

* **Accessing and Manipulating Properties:**
  * **Dot Notation (`object.propertyName`):** Direct and clean syntax for standard identifiers.
  * **Bracket Notation (`object["propertyName"]`):** Required for dynamic property names (variables) or keys containing spaces/special characters.
  * **Adding/Modifying:** Assigning a value to `obj.key` or `obj["key"]` updates existing keys or creates new ones.
  * **Deleting:** The `delete` operator removes a key-value pair from an object (`delete obj.key`).

### **1. Concept Explanation**

* **Regular Expression (RegExp):** A sequence of characters forming a search pattern used to match, search, validate, and extract character combinations from strings.
* **Creating Regular Expressions (from Unit 2 notes):**
  1. **Literal Notation:** `let pattern = /abc/i;` (Evaluated when the script loads).
  2. **Constructor Notation:** `let pattern = new RegExp("abc", "i");` (Evaluated at runtime).
* **Modifiers (Flags):**
  * `i` (Case-Insensitive): Performs pattern matching regardless of uppercase or lowercase letters.
  * `g` (Global): Finds all matching occurrences throughout the string rather than stopping at the first match.
  * `m` (Multiline): Enables `^` and `$` to match the start and end of each individual line.
* **RegExp Validation Methods:**
  * **`.test(string)`:** Tests for a pattern match and returns `true` if valid, or `false` if invalid.
  * **`.exec(string)`:** Searches a string and returns an array of match details or `null`.
* **Common Pattern Building Blocks (Metacharacters & Quantifiers):**
  * `^` / `$`: Start of string / End of string.
  * `\d`: Any numeric digit (`0-9`).
  * `\w`: Any word character (`a-z`, `A-Z`, `0-9`, `_`).
  * `{n}` / `{n,m}`: Matches exactly `n` occurrences, or between `n` and `m` occurrences.
  * `+`: Matches 1 or more occurrences.
