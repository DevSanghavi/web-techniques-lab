<iframe> and the target Attribute

The frame below has name="contentFrame". Each link uses target="contentFrame", so the page opens inside the frame and this page does not reload.

  • Map of Pune
  • Example.com
  • W3C Home

A form can target the frame too

Common values of the target attribute
Value Where the link opens
_self Same window (default)
_blank New tab or window
_parent Parent frame
_top Full window
frameName The iframe with that name
